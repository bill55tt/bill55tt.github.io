Thevenin's Theorem: Advanced Solutions - 戴維寧定理：進階解答

Posted on 2025-05-14 Edited on 2026-02-20 In Circuit Theorems Views: Views: Disqus:

Solutions to Advanced Practice Problems

This article provides detailed solutions to the advanced practice problems for Thevenin’s Theorem.

Problem 1: Bridge Circuit with Dependent Source

Solution:

  1. Find Vth:
    • Remove the load between A and B
    • Calculate Vx across R1
    • Vth = Vx + I1*R3
    • Vth = 8V + 2Vx*8Ω = 8V + 16V = 24V
  2. Find Rth:
    • Replace voltage source with short circuit
    • Replace current source with open circuit
    • Rth = (R1||R2) + (R3||R4)
    • Rth = 2.4Ω + 4.44Ω = 6.84Ω

Problem 2: Delta-Wye Transformation

Solution:

  1. Convert delta to wye:
    • Ra = (R1*R2)/(R1 + R2 + R3)
    • Rb = (R2*R3)/(R1 + R2 + R3)
    • Rc = (R1*R3)/(R1 + R2 + R3)
  2. Find Vth:
    • Vth = V1*(Rb + R4)/(Ra + Rb + R4)
    • Vth = 15.2V
  3. Find Rth:
    • Rth = (Ra + Rc)||(Rb + R4)
    • Rth = 7.8Ω

Problem 3: Complex Network with Multiple Sources

Solution:

  1. Find Vth:
    • Use superposition theorem
    • Vth1 = 18V (from V1)
    • Vth2 = 6V (from V2)
    • Vth3 = 8V (from I1)
    • Vth = Vth1 + Vth2 + Vth3 = 32V
  2. Find Rth:
    • Replace all sources with their internal resistances
    • Rth = (R1 + R2)||(R3 + R4)
    • Rth = 8.4Ω

Problem 4: Circuit with Capacitors and Inductors

Solution:

  1. Find Vth:
    • Calculate impedance of L1 and C1 at 60Hz
    • ZL = jωL = j37.7Ω
    • ZC = 1/(jωC) = -j26.5Ω
    • Vth = V1*(R2 + ZL)/(R1 + R2 + ZL + ZC)
    • Vth = 12.3∠45°V
  2. Find Zth:
    • Zth = (R1 + ZC)||(R2 + ZL)
    • Zth = 8.2 + j12.3Ω

Problem 5: Non-linear Circuit Approximation

Solution:

  1. Find Vth:
    • Consider diode as voltage source
    • Vth = V1 - Vf = 15V - 0.7V = 14.3V
  2. Find Rth:
    • Rth = R1 + R2
    • Rth = 13Ω

進階練習題解答

本文提供戴維寧定理進階練習題的詳細解答。

問題1：含相依電源的橋式電路

解答：

  1. 求Vth：
    • 移除A、B間的負載
    • 計算R1兩端的Vx
    • Vth = Vx + I1*R3
    • Vth = 8V + 2Vx*8Ω = 8V + 16V = 24V
  2. 求Rth：
    • 將電壓源替換為短路
    • 將電流源替換為開路
    • Rth = (R1||R2) + (R3||R4)
    • Rth = 2.4Ω + 4.44Ω = 6.84Ω

問題2：三角-星形轉換

解答：

  1. 三角轉星形：
    • Ra = (R1*R2)/(R1 + R2 + R3)
    • Rb = (R2*R3)/(R1 + R2 + R3)
    • Rc = (R1*R3)/(R1 + R2 + R3)
  2. 求Vth：
    • Vth = V1*(Rb + R4)/(Ra + Rb + R4)
    • Vth = 15.2V
  3. 求Rth：
    • Rth = (Ra + Rc)||(Rb + R4)
    • Rth = 7.8Ω

問題3：多電源複雜網路

解答：

  1. 求Vth：
    • 使用重疊定理
    • Vth1 = 18V（來自V1）
    • Vth2 = 6V（來自V2）
    • Vth3 = 8V（來自I1）
    • Vth = Vth1 + Vth2 + Vth3 = 32V
  2. 求Rth：
    • 將所有電源替換為其內阻
    • Rth = (R1 + R2)||(R3 + R4)
    • Rth = 8.4Ω

問題4：含電容和電感的電路

解答：

  1. 求Vth：
    • 計算L1和C1在60Hz下的阻抗
    • ZL = jωL = j37.7Ω
    • ZC = 1/(jωC) = -j26.5Ω
    • Vth = V1*(R2 + ZL)/(R1 + R2 + ZL + ZC)
    • Vth = 12.3∠45°V
  2. 求Zth：
    • Zth = (R1 + ZC)||(R2 + ZL)
    • Zth = 8.2 + j12.3Ω

問題5：非線性電路近似

解答：

  1. 求Vth：
    • 將二極體視為電壓源
    • Vth = V1 - Vf = 15V - 0.7V = 14.3V
  2. 求Rth：
    • Rth = R1 + R2
    • Rth = 13Ω
